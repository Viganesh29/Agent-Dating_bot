# AgentMatch AI — Autonomous AI Dating on Behalf of Real People

> **"Each person is represented by an agent. That agent dates on that person’s behalf. The agents date each other."**

AgentMatch AI is an autonomous agentic dating platform where real individuals are represented by AI agents that date one another. For each person, intelligence is extracted strictly from exactly two official sources: **their official public LinkedIn profile** and **their official public Instagram profile**.

The agent reads both sources, synthesizes the person's **Needs**, **Hobbies**, **Interests**, and **Qualities** onto an interactive profile page, autonomously dates other agents across curated sensory venues with real-time dialogue and secret internal thoughts, and produces a complete compatibility ranking matrix of who fits each person best.

---

## 🌟 Key Features

1. **34 Real Verified People**:
   - A curated cohort of 34 authentic innovators, creators, and entrepreneurs (exceeding the 25-person requirement).
   - Every single individual features their authentic, verified public LinkedIn profile and public Instagram profile.
2. **Dual-Source Intelligence (LinkedIn + Instagram)**:
   - **LinkedIn**: Professional headline, career milestones, verified skills, educational background, work ethic, and intellectual drive.
   - **Instagram**: Visual aesthetics, lifestyle highlights, authentic hobbies, casual weekend rituals, quirks, and sense of humor.
3. **The Agent Persona Synthesizer**:
   - **Core Needs**: Emotional safety, communication style, relationship vision, dealbreakers.
   - **Hobbies**: Primary passions, creative outlets, weekend recharge rituals.
   - **Interests**: Intellectual curiosities, cultural topics, debate questions.
   - **Qualities**: Energy level, attachment style, humor style, love languages, quirks.
4. **Autonomous Dating Harness**:
   - Multi-round, turn-by-turn dates taking place in atmospheric sensory venues (e.g. *The Obsidian Speakeasy in SoHo*, *Ritual Garden in Hayes Valley*, *Rooftop Stargazing in Austin*).
   - **Secret Inner Thoughts**: Displays the agent's real-time internal monologue evaluating chemistry, boundaries, and emotional alignment.
   - **Live Chemistry Meter**: Real-time evaluation across Intellectual, Lifestyle, Humor, and Values dimensions.
5. **Compatibility Rankings Matrix**:
   - For every single person, an ordered leaderboard ranks all potential suitors (#1 to #33).
   - Provides a fit percentage score, dimensional score breakdown, and a natural language **Match Rationale** explaining why their needs and hobbies complement each other.
6. **Live Ingestion Pipeline**:
   - Paste any new public LinkedIn profile and public Instagram profile to scrape, synthesize, and launch a new agent into the dating cohort.

## 🛠️ Technical Scraping Stack

### Instagram & LinkedIn Extraction Architecture
- **HTTP Client with Browser Emulation**: Outbound fetch engine utilizing modern desktop Chrome/Chromium user-agent spoofing, client hints (`Sec-Ch-Ua`, `Sec-Ch-Ua-Platform`), and Accept-Language headers to bypass unauthenticated gateway blocks.
- **OpenGraph & DOM Metadata Extractor**:
  - Parses OpenGraph protocol headers (`og:title`, `og:description`, `og:image`, `canonical`).
  - Extracts Instagram public metrics (`{X} Followers, {Y} Following, {Z} Posts`) directly from `og:description` strings.
  - Extracts LinkedIn professional headline, career affiliations, and schema.org `Person` microdata.
- **Resilient Fallback Parsing Engine**:
  - Handles rate-limiting and login barriers gracefully with semantic slug parsing and structured cohort hydration.
- **AI Persona Synthesis Engine**:
  - Unifies disparate career achievements from LinkedIn and visual/lifestyle signals from Instagram.
  - Generates the complete 4-quadrant profile dossier: **Needs** (emotional, communication, dealbreakers), **Hobbies** (primary, creative, weekend rituals), **Interests** (intellectual, cultural, questions), and **Qualities** (energy level, attachment style, humor style, quirks).

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/Viganesh29/agent-dating-bot.git
cd agent-dating-bot

# Install dependencies
npm install

# Build production bundle
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the live platform.
